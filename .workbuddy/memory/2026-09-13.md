# 2026-09-13

## API 请求增加 1s 超时

- 需求：查询 API 时增加 1 秒超时。
- 新增 `src/integrations/withTimeout.ts`：导出 `REQUEST_TIMEOUT = 1000` 和泛型 `withTimeout(promise, timeout=1000)`，用 `window.setTimeout` + `Promise.race` 实现，超时 reject `Request timed out after 1000ms`。（Obsidian 的 `request`/`requestUrl` 本身不支持 timeout，故需自行包装。）
- 已包装所有远程 API 调用站点：
  - `freeDictionaryAPI.ts`（`request` ×2）
  - `googleScraperAPI.ts`（`requestUrl`）
  - `jishoAPI.ts`（`requestUrl`，顺便补上了缺失的 `import { requestUrl } from "obsidian"`）
  - `altervistaAPI.ts`、`openThesaurusAPI.ts`、`synonymoAPI.ts`（`request`）
  - `systranAPI.ts`（`fetch`）
- 刻意未包装 `offlineDic.ts` 中从 GitHub 下载 dictionary.json 的 `request`（大文件下载，1s 会导致首次下载失败）。离线词典为本地查询，无需超时。
- 构建：`node esbuild.config.mjs production` 通过（仅剩既有 Svelte a11y 警告）。
- 注意：1s 对 Google 抓取类请求偏紧，可能频繁超时；如需放宽可调 `REQUEST_TIMEOUT`。
- 项目构建脚本仅用 esbuild（不做类型检查），`obsidian` 依赖为 0.12.17，其 d.ts 不含 `requestUrl` 类型，但不影响构建。
